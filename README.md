# Aldwynn Urbistondo - Personal Portfolio

Personal portfolio website made with HTML, CSS, and JavaScript. No React, Node.js, or build process required.

## Files

- `index.html` - Main page (Home, About, Portfolio, Contact)
- `styles.css` - Layout, styles, and responsive design
- `script.js` - Mobile menu, active navigation, and copyright year
- `assets/games/` - Five game cover images supplied for the Flintlock Games portfolio
- `assets/favicon.svg` - Small website icon

## Open locally

Double-click `index.html` and open it in your browser.

## Deploy to Vercel via GitHub

1. Create a repository, such as `aldwynn-portfolio`.
2. Upload **the contents of this folder** directly to the repository root. `index.html` must be visible at the top level of the repository.
3. In Vercel, select **Add New > Project** and import the repository.
4. Use Framework Preset **Other** and Root Directory **./**.
5. Leave Build Command and Install Command blank. Use the default output setting for a static site.
6. Deploy.
